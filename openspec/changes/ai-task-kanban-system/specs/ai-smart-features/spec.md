## ADDED Requirements

### Requirement: AI 驱动的标签与工时建议
系统必须调用大语言模型（LLM）API，根据任务描述生成建议的标签和预估工时。

#### Scenario: 用户输入任务描述
- **WHEN** 用户在任务详情面板中输入任务描述，并停止输入至少 3 秒
- **THEN** 系统必须将描述文本发送到 LLM API，并显示加载指示器，文字为 "AI 正在分析任务..."

#### Scenario: AI 生成标签和工时建议
- **WHEN** LLM API 返回响应
- **THEN** 系统必须显示建议的标签（最多 5 个）和预估工时，每项都附带"采纳"按钮和"拒绝"按钮

#### Scenario: 用户采纳 AI 建议的标签
- **WHEN** 用户点击 AI 建议标签上的"采纳"按钮
- **THEN** 系统必须将标签添加到任务的标签列表，用对勾动画直观确认采纳，并为该建议隐藏"采纳"/"拒绝"按钮

#### Scenario: 用户拒绝 AI 建议的标签
- **WHEN** 用户点击 AI 建议标签上的"拒绝"按钮
- **THEN** 系统必须用淡出动画从显示中移除该建议

#### Scenario: 用户采纳 AI 建议的工时预估
- **WHEN** 用户点击 AI 建议的预估工时上的"采纳"按钮
- **THEN** 系统必须用建议值填充任务的"预估工时"字段

#### Scenario: 用户拒绝 AI 建议的工时预估
- **WHEN** 用户点击 AI 建议的预估工时上的"拒绝"按钮
- **THEN** 系统必须从显示中移除该建议，"预估工时"字段保持不变

#### Scenario: LLM API 调用失败或超时
- **WHEN** LLM API 请求失败、超时（超过 15 秒）或返回错误响应
- **THEN** 系统必须显示错误消息 "AI 建议暂时不可用，请稍后重试"，隐藏加载指示器，且不阻止用户继续编辑任务

#### Scenario: 任务描述太短无法进行有意义的 AI 分析
- **WHEN** 用户输入的任务描述少于 10 个字符
- **THEN** 系统不得调用 LLM API（避免无意义的建议）

### Requirement: 自然语言批量操作指令
系统必须解析自然语言指令并执行相应的任务批量操作。

#### Scenario: 用户提交有效的自然语言指令
- **WHEN** 用户在 AI 指令输入框中输入"把所有逾期任务标记为紧急"等自然语言指令并提交
- **THEN** 系统必须将指令发送到 LLM API 进行解析，API 返回结构化批量操作命令，识别目标任务过滤条件（如"status=overdue"）和操作（如"set priority=urgent"）

#### Scenario: 系统执行解析后的批量操作
- **WHEN** LLM 返回有效的解析操作
- **THEN** 系统必须执行批量操作，显示更改摘要（如"已将 5 个逾期任务标记为紧急"），并通过 WebSocket 向所有连接的客户端广播更新后的任务

#### Scenario: 用户提交模糊或不支持的指令
- **WHEN** 用户提交 LLM 无法解析为有效批量操作的自然语言指令（如"让所有任务变得更好"）
- **THEN** 系统必须显示错误消息 "无法理解该指令，请尝试更明确的描述，如「把所有逾期任务标记为紧急」"

#### Scenario: 批量操作具有破坏性需确认
- **WHEN** 解析的批量操作会删除任务或产生不可逆更改
- **THEN** 系统必须在执行前显示确认对话框，详细说明受影响的任务数量和具体操作

#### Scenario: 没有任务符合批量操作条件
- **WHEN** 解析的批量操作针对的过滤条件匹配零个任务
- **THEN** 系统必须显示消息 "没有找到符合条件的任务"，且不执行任何更改

#### Scenario: AI 指令输入为空
- **WHEN** 用户提交空或仅包含空白字符的 AI 指令输入
- **THEN** 系统必须显示错误消息 "请输入指令"，且不调用 API

#### Scenario: 指令解析过程中 LLM API 失败
- **WHEN** 指令解析的 LLM API 请求失败或超时
- **THEN** 系统必须显示错误消息 "AI 指令解析失败，请稍后重试"，且不执行任何批量操作
