## ADDED Requirements

### Requirement: 任务详情侧边栏
当用户点击任务卡片时，系统必须从屏幕右侧滑出显示完整任务详情的面板。

#### Scenario: 用户点击任务卡片
- **WHEN** 用户点击看板中的任务卡片
- **THEN** 系统必须从屏幕右侧滑出详情面板，显示任务的标题、描述、优先级、截止日期、负责人和附件列表

#### Scenario: 面板打开时用户点击另一个任务
- **WHEN** 用户在详情面板已打开时点击另一个任务卡片
- **THEN** 系统必须转换面板内容以显示新选中任务的详情，而不关闭和重新打开面板

#### Scenario: 用户关闭详情面板
- **WHEN** 用户点击详情面板上的关闭按钮，或点击面板外看板区域
- **THEN** 系统必须将面板滑出关闭到右侧

### Requirement: 任务字段编辑与实时同步
系统必须允许用户编辑任务字段（标题、描述、优先级、截止日期、负责人），并支持自动保存和 WebSocket 同步。

#### Scenario: 用户内联编辑任务标题
- **WHEN** 用户在详情面板中修改任务标题，且输入框失去焦点或用户按 Enter 键
- **THEN** 系统必须立即保存更改，通过 WebSocket 向所有连接的客户端广播更新后的标题，并在所有打开的看板上更新对应的任务卡片

#### Scenario: 用户编辑任务描述
- **WHEN** 用户在详情面板中修改任务描述
- **THEN** 系统必须在用户停止输入 2 秒后（防抖）自动保存更改，并通过 WebSocket 广播更新

#### Scenario: 用户更改任务优先级
- **WHEN** 用户为任务选择不同的优先级级别（如"低"、"中"、"高"、"紧急"）
- **THEN** 系统必须立即保存新的优先级并通过 WebSocket 广播更改，任务卡片必须直观地反映新的优先级颜色

#### Scenario: 用户设置或更改任务截止日期
- **WHEN** 用户设置或修改任务的截止日期
- **THEN** 系统必须验证日期不是过去（除非故意设置），保存更改，并通过 WebSocket 广播

#### Scenario: 用户设置过去的截止日期
- **WHEN** 用户尝试设置早于当前日期的截止日期
- **THEN** 系统必须接受该值，但在任务卡片上显示视觉警告标识

#### Scenario: 用户分配或更改任务负责人
- **WHEN** 用户从成员下拉列表中选择项目成员作为任务负责人
- **THEN** 系统必须更新负责人，通过 WebSocket 广播更改，并向新分配成员发送站内信通知

#### Scenario: 并发编辑冲突
- **WHEN** 两个用户同时修改同一任务的同一字段
- **THEN** 系统必须采用 last-write-wins 策略，并向所有客户端广播最终值；每个客户端必须更新视图以反映最新的服务器状态

### Requirement: 附件上传与校验
系统必须允许用户上传任务附件，并进行类型和大小校验。

#### Scenario: 用户上传有效的图片附件
- **WHEN** 用户上传不超过 10MB 的图片文件（PNG、JPG、GIF 或 WebP）
- **THEN** 系统必须将文件保存到服务器，创建链接到任务的附件记录，并在详情面板中显示附件缩略图

#### Scenario: 用户上传有效的文档附件
- **WHEN** 用户上传不超过 10MB 的文档文件（PDF、DOC、DOCX、XLS、XLSX 或 TXT）
- **THEN** 系统必须将文件保存到服务器，创建链接到任务的附件记录，并在详情面板中显示附件及其文件类型图标

#### Scenario: 用户上传超过大小限制的文件
- **WHEN** 用户尝试上传大于 10MB 的文件
- **THEN** 系统必须返回 HTTP 413，错误消息为 "文件大小不能超过10MB"

#### Scenario: 用户上传不支持的文件类型
- **WHEN** 用户尝试上传不支持的扩展名文件（不在允许的图片或文档类型中）
- **THEN** 系统必须返回 HTTP 400，错误消息为 "不支持的文件类型，支持的格式：图片（PNG/JPG/GIF/WebP）和文档（PDF/DOC/DOCX/XLS/XLSX/TXT）"

#### Scenario: 用户删除附件
- **WHEN** 用户点击现有附件上的删除按钮
- **THEN** 系统必须弹出确认提示，确认后将文件从服务器删除并从数据库中移除附件记录

### Requirement: 任务删除需确认
系统在永久删除任务前必须要求用户确认。

#### Scenario: 用户确认后删除任务
- **WHEN** 用户点击任务上的删除按钮
- **THEN** 系统必须显示确认对话框，询问"确定要删除该任务吗？此操作不可撤销"；用户确认后，系统必须从数据库中永久删除任务记录和所有相关附件，并通过 WebSocket 向所有连接的客户端广播删除

#### Scenario: 用户取消任务删除
- **WHEN** 用户在任务删除确认对话框中点击"取消"
- **THEN** 系统必须关闭对话框，不做任何更改
